🤖 Connect & Launch Live Discord Bot

Follow these 4 simple steps to run your Discord Bot live!

How to Setup Discord Bot Application:

  1. Go to the Discord Developer Portal and click New Application.
  2. Go to Bot section and click Reset Token / Copy Token.
  3. Enable MESSAGE CONTENT INTENT under Privileged Gateway Intents.
  4. Go to OAuth2 -> URL Generator, check bot scope and permissions (Send Messages, Embed Links, Attach Files, Read Message History), then invite bot to your Discord server!
  5. Paste the Bot Token below and click Launch Discord Bot!
